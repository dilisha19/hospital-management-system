# New Hospital: Hospital Management System

A web app to manage patients, doctors and appointments, built with ASP.NET Web Forms, C# and SQL Server.

## Features
- Register and log in (hashed passwords, parameterized SQL)
- Dashboard with live counts and upcoming appointments
- Patients: add, edit, delete, search
- Doctors: add, edit, delete, search
- Appointments: booking with double-booking prevention

## Tech stack
ASP.NET Web Forms (.NET Framework 4.8), C#, SQL Server Express, HTML/CSS
